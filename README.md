# KrishaCards - Invitation Card Making Store Website

A modern, clean, and beginner-friendly invitation card store website built using **React.js, HTML, CSS, Bootstrap, and React Icons**.

🌐 **Live GitHub Pages URL**: [https://charanbalaji152005-pixel.github.io/invitation/](https://charanbalaji152005-pixel.github.io/invitation/)  
📦 **GitHub Repository**: [https://github.com/charanbalaji152005-pixel/invitation.git](https://github.com/charanbalaji152005-pixel/invitation.git)

---

## 🌟 Pages Included (Strictly 6 Pages)

1. **Home (`/`)**: Hero banner with headline *"Beautiful Invitations for Every Special Moment"*, "Explore Cards" and "Customize Now" call-to-actions, popular category grid, featured invitation cards, and customer reviews.
2. **Wedding Invitations (`#/wedding`)**: Rose Pink & Gold palette, responsive React carousel of wedding highlights, category filter pills (*Traditional Wedding, Modern Wedding, Royal Wedding, South Indian Wedding, Engagement, Reception*), and cards with price, rating, and customization triggers.
3. **Birthday Invitations (`#/birthday`)**: Vibrant Orange & Blue palette, animated carousel, categories (*Kids Birthday, 1st Birthday, Teen Birthday, Adult Birthday, Surprise Party, Theme Birthday*) with hover zoom effects.
4. **Other Events (`#/events`)**: Fresh Green & Yellow palette, distinct background colors for each category (*Baby Shower, Housewarming, Anniversary, Graduation, Naming Ceremony, Festival, Corporate Events*), and carousel.
5. **Card Details / Customization (`#/customize`)**: Lavender & White palette, template picker, live interactive card previewer updating in real-time with React state (*Celebrant Names, Event Title, Date, Time, Venue, Color harmonies, Fonts, and Sizes*). Clicking **"Add to Order"** passes the customized details directly to the Contact/Order page.
6. **Contact / Order (`#/contact`)**: Dark Blue & Light Blue palette, order & enquiry form prefilled from the customizer, **"Place Order"** and **"Send Enquiry"** buttons, store address (*MG Road Bengaluru*), phone, email, and social media links.

## 🚀 Running Locally & Deploying

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Deploy to GitHub Pages
npm run deploy
```
